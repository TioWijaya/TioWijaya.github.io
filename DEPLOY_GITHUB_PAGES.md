# Portfolio Tio Wijaya

Paket ini siap dipublikasikan ke GitHub Pages.

## Cara membuat website online
1. Login ke GitHub.
2. Buat repository baru bernama `tio-wijaya.github.io` jika username GitHub kamu adalah `tio-wijaya`.
3. Upload `index.html`, `style.css`, `script.js`, `foto-tio.jpg`, dan `.nojekyll` ke repository.
4. Buka **Settings → Pages**.
5. Pada **Build and deployment**, pilih **Deploy from a branch**.
6. Pilih branch `main` dan folder `/ (root)`, lalu Save.
7. Tunggu beberapa menit. Website akan tersedia di `https://USERNAME.github.io/`.

## Catatan
- Semua file website harus berada pada folder root repository.
- Ganti link LinkedIn di `index.html` dengan URL profil LinkedIn asli.
- Tombol WhatsApp sudah diarahkan ke nomor yang tercantum pada portfolio.
