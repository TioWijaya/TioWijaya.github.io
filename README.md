# Tio Wijaya — Portfolio Website

Website portfolio personal modern, responsive, dan tanpa framework.

## Cara menjalankan
1. Ekstrak folder.
2. Buka `index.html` di browser.
3. Untuk editing, buka folder ini di VS Code.

## File
- index.html — struktur halaman
- style.css — desain dan responsive layout
- script.js — animasi, mobile menu, dan active navigation

## Kustomisasi foto
Bagian foto saat ini menggunakan inisial "TW". Jika ingin memakai foto asli, ganti elemen `.profile-photo` di index.html dengan `<img>` dan tambahkan file foto ke folder project.
